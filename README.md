## Supply Chain & Inventory Management Analysis Using SQL

1. Project Overview

This project explores supply chain and inventory management data using MySQL to generate actionable business insights. The analysis focuses on product demand, inventory planning, purchasing costs, supplier performance, and procurement activity.

The objective is to demonstrate how SQL can be used to transform raw data into meaningful insights that support operational efficiency, inventory optimization, and data-driven decision-making.

2. Business Objectives

Analyze product demand across different product categories.

Evaluate estimated inventory requirements and safety stock levels.

Identify products associated with high purchasing costs.

Evaluate supplier performance and estimated delivery delays.

Identify potential risks associated with single-supplier dependency.

Analyze geographic sourcing patterns.

Evaluate purchasing concentration across suppliers.

3. Dataset Description

The analysis utilizes three relational database tables containing information about products, suppliers, and purchase orders.

Dataset

Description

Items

Contains product information, categories, unit costs, daily demand, and safety stock coverage requirements.

Suppliers

Contains supplier information, geographic regions, quoted lead times, and lateness factors.

Purchase Orders

Contains historical purchasing records connecting products with their respective suppliers.
